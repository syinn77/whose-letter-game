# ✉️ Whose letter?｜未寄出的信件

**四封信，一段人生。**

有些感謝，來不及說出口。  
有些關愛，藏在平凡的日常裡。  
有些歉意，始終沒有勇氣傳達。  
有些告別，成為心中珍貴的回憶。

## 📖 遊戲簡介

《Whose letter?》是一款以高中生命教育「四道人生」為主題的敘事探索型 RPG 遊戲，透過郵局情境、解謎任務與生命反思，引導玩家思考感謝、關愛、道歉及道別的意義。

玩家扮演一位 17 歲的高中生，因學校安排的社區服務學習，來到一間即將結束營業的老郵局。

郵局管理員「韋」告訴玩家，郵局曾設有一面「未寄出的信件」展示牆，但其中四封匿名信件在整理過程中不慎散落於不同部門。

玩家需要探索郵局、完成任務，找回四封信件，並逐漸理解信件背後的生命故事。

**究竟，這四封信是誰寫下的？**

## 🎮 遊戲特色

- **自由探索：** 玩家可以自行決定四個房間的探索順序。
- **情境解謎：** 透過郵局日常工作情境，完成不同類型的互動任務。
- **生命反思：** 運用 Borton 三階段反思，引導玩家連結自身生活經驗。
- **信件典藏：** 可以收藏、重新閱讀四封信件與個人反思紀錄。
- **未來書信：** 故事結束後，可以撰寫一封信給未來的自己。

## 🏤 四個探索關卡

| 生命主題 | 探索場景 | 主要任務 |
|---|---|---|
| 💛 道愛之信 | 員工休息室 | 將三張便利貼放回正確位置 |
| 💌 道謝之信 | 郵件分類室 | 根據郵遞區號分類三封感謝信 |
| 🤝 道歉之信 | 包裹收發室 | 調查異常包裹，找出退回原因 |
| 🍂 道別之信 | 舊檔案室 | 調查郵局歷史資料，解開封存櫃密碼 |

四個關卡沒有固定順序，玩家可以自由探索。

## 🌱 Borton 三階段生命反思

玩家取得信件後，會進入對應的反思介面，透過三個階段思考自身經驗：

| 反思階段 | 反思方向 |
|---|---|
| **What?** | 經驗回顧：曾經發生了什麼事情？ |
| **So What?** | 經驗分析：這段經驗帶來什麼感受與意義？ |
| **Now What?** | 未來行動：未來希望如何面對或改變？ |

遊戲沒有標準答案，玩家可以依照自己的生活經驗自由書寫。

## 💌 寫給未來的自己

完成遊戲後，玩家可以選擇：

**1. 十年後，寄一封信給我**

撰寫信件並填寫 Email，提交後由系統保存，規劃於十年後由研究者人工寄送。

**2. 現在收藏，留給未來的我**

將寫好的信件下載為 PNG 圖片，自行收藏，不需填寫 Email，也不提交信件內容至後端。

## 🛠️ 技術與系統

本遊戲使用 **RPG Maker MV** 製作，並搭配自製 JavaScript 插件：

| 插件 | 功能 |
|---|---|
| `WhoseLetter_QuestHUD.js` | 任務提示與信件蒐集進度 |
| `WhoseLetter_ExploreUI.js` | 地圖、道具與房間名稱顯示 |
| `XY_BortonReflection.js` | Borton 三階段文字反思 |
| `XY_LetterArchive.js` | 信件典藏與反思紀錄回顧 |

延伸書信網頁使用 HTML、Google Apps Script 與 Google Sheets 建立。
